### [`scripts/wxo_test_agent.py`](scripts/wxo_test_agent.py)

Key design points:

- **IAM token** — reuses [`app/services/ibm_auth.iam_token()`](app/services/ibm_auth.py) directly; token is refreshed between scenario calls.
- **Agent lookup** — `GET /v1/orchestrate/agents` → finds the agent by `name == "savealife_dispatch"`, handles both `agent_id` and `id` key shapes.
- **Endpoint discovery** — `GET /v1/orchestrate/openapi.json` scans paths for one matching `chat` + `run`; falls back to `POST /v1/orchestrate/agents/{agent_id}/chat/runs` if discovery fails. The endpoint actually used is documented in the module docstring and printed at runtime.
- **Async 202 support** — if the endpoint returns 202, [`_poll_run()`](scripts/wxo_test_agent.py:130) polls `Location` or `run_url` until `status == "completed"`.
- **Assertions** — checks `"RECOMMEND AIR"` in the answer for S2, `"RECOMMEND ROAD"` for S1/S3/S4/S5; prints a final summary table, exits non-zero on failure.
