### [`scripts/wxo_test_agent.py`](scripts/wxo_test_agent.py)

**Removed:**

- `_extract_text()` — the old multi-shape response parser.
- `_run_chat()` — the old function that used the `/chat/runs` default URL with 202-fallback.
- The "Discovering chat endpoint…" block in `main()`.

**Added / changed:**
- `_start_run(client, token, agent_id, message) → (run_id, thread_id)` — POSTs to `POST /v1/orchestrate/runs` with `{"message": {"role": "user", "content": …}, "agent_id": …}`.
- `_poll_run(client, token, run_id) → dict` — polls `GET /v1/orchestrate/runs/{run_id}` every **1 s** (was 3 s) until `status == "completed"` or terminal, returns the raw run object.
- `_fetch_answer(client, token, thread_id) → str` — GETs `/v1/orchestrate/threads/{thread_id}/messages`, walks backwards for the last `role == "assistant"` message, and handles both plain-string and `[{"response_type":"text","text":…}]` list content.
- `_count_tool_calls(run_body, messages) → str` — inspects `step_history`, `tool_calls` on the run object, then `role == "tool"` messages; returns a count string or `"n/a"`.
- The per-scenario loop now calls these three functions, records `elapsed` (wall-clock seconds) and `tool_count`, prints them per scenario, and includes them in the summary table columns.
- `results` tuple expanded to `(sid, exp, ans, ok, elapsed, tool_count)`.
